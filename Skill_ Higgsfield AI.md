# Skill: Higgsfield AI

## Overview
Higgsfield AI is a platform used for creating high-quality images and AI models that can be integrated into web design and animation workflows. It is particularly noted for its "Nano Banana" model and "GAPS" AI model.

## Key Features
- **Nano Banana Model**: A recommended model for creating high-quality images that are optimized for animation.
- **GAPS AI Model**: A breakthrough AI model used for building advanced product concepts and designs.
- **Animation Workflow**: Images created in Higgsfield can be animated using tools like Kling 3.0 to create continuous video effects for websites.

## Usage in Web Design
1. Generate base images using Higgsfield (e.g., using the Nano Banana model).
2. Animate the images using a video generation tool (e.g., Kling 3.0).
3. Integrate the resulting video into a website using Claude Code to create immersive 3D or scrolling effects.
