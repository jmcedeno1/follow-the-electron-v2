## Audio Transcription (Spanish)

"Mucha gente me pregunta cómo es que hago este tipo de páginas webs, así que hoy lo van a descubrir y se van a dar cuenta que es un proceso muy simple. Primero que nada lo que necesitamos es una foto de un cohete, así que simplemente la busqué por internet y elegí esta. Así que lo que vamos a hacer es copiar esta imagen, vamos a ir a un chat de Claude y se la vamos a pegar. 
Ahora agregamos este prompt que lo que hace es generar otro prompt pero para el modelo de generación de imagen de nanobanana, ya van a ver por qué. Una vez que ya lo ejecutamos, Claude nos da estos prompts, simplemente lo vamos a copiar, vamos a ir a la herramienta de Google AI Studio donde tenemos acceso al modelo de nanobanana pro y lo último que vamos a hacer es copiar nuevamente esta imagen y la vamos a pegar en el modelo de generación de imagen. 
Una vez que Google ya hizo su ejecución nos va a devolver esta imagen de acá que es la que vamos a usar para la hero section de la página, es decir lo primero que ve la persona. Ahora vamos a seguir un proceso muy similar que es simplemente copiar esta imagen, volver al chat de Claude, se la vamos a pasar, le vamos a volver a pegar otro prompt en este caso que lo que va a hacer es generarnos una animación de video para que este cohete tenga movimiento, despegue y vuele un poco. 
Una vez que Claude ya nos generó el prompt vamos a volver a copiarlo, vamos a volver al modelo de generación de imagen pero ahora vamos a elegir la generación de video con el modelo de Google VEO 3. Vamos a pegar el prompt y acá muy interesante queremos generar un video en bucle, es decir queremos que termine de la misma manera en la que empieza. Entonces en el start frame vamos a seleccionar la imagen y para el last frame también vamos a seleccionar la misma imagen. Como ven es la misma. 
Una vez que ya haya terminado nos va a dar este video. Vas a ir a Claude Design que es otra plataforma de Claude, creas un nuevo proyecto, añadís el video que acabas de descargar, le vamos a pedir a Claude otro prompt para que nos genere la hero section. Volvemos a Claude Design y volvemos a pegar este prompt. Acá le damos a send y por acá ya tenemos el resultado final. Incluso si queremos editarlo podemos editar los colores o cualquier cosa que queramos. 
Ahora lo último que queda es terminar la página. Entonces vamos a ir acá arriba a la derecha donde dice share y vamos a poner la última opción para pasarle esta página a Claude Code. Y le vamos a pedir a Claude un último prompt para que pueda terminar la página ahora desde Claude Code. Simplemente vamos a copiar la respuesta, vamos a volver a Claude Code, vamos a pegarla y vamos a esperar hasta que corra. 
Y listo amigos, ya la tienen. Esta es la forma de crear una página web con estas características, este nivel de profesionalismo, así que guardá este video para cuando vayas a crear la tuya."
