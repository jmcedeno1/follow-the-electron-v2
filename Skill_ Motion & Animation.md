# Skill: Motion & Animation

## Overview
The "Motion" skill refers to the integration of animation libraries and video effects into web projects to create dynamic, interactive user experiences.

## Key Tools
- **Framer Motion**: An open-source React library used for creating smooth animations and transitions.
- **Kling 3.0**: An AI video generation tool used to create continuous video loops from static images.
- **Scrolling Effects**: Using video backgrounds that respond to user scroll input to create a 3D-like experience.

## Implementation Workflow
1. **Animation**: Install Framer Motion via Claude Code to add interactive animations to UI elements.
2. **Video Integration**: Use AI-generated videos (e.g., from Kling 3.0) as backgrounds.
3. **Scroll Sync**: Program the website to sync video playback or movement with the user's scroll position.
